Instructions

Required columns: Campaign name, Date, Cost, Conversions, Conversion Value, Clicks
Optional columns: Campaign ID, Campaign Type, Impressions, Impression Share, Click Share
Upsert: Existing rows (same campaign + date) are updated; new rows are created.
Vertical scoping: All campaign matching and brand assignment is scoped to the selected vertical. Select the correct vertical before uploading.
Auto-create: Unknown campaigns are created with brand set to "Unknown" within the selected vertical. Campaign type is read from the CSV (or defaults to "Uncategorized"). Assign the correct brand via Match Campaigns.
Matching: Campaigns are matched by external ID first, then by name (within the selected vertical).
Supported sources: Google Ads, Bing Ads, Meta Ads, Amazon Marketplace.
Amazon: Select Sponsored Ads (paid media) or Feed-based Listings (non-paid, cost defaults to 0).
